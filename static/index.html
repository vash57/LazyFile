Safety model

The cautious part is the feature.

LazyFile is designed for the moment after a mistake. These rules are enforced in the backend, not just the interface.

Preview is mandatory

Scanning and previewing are read-only. A move requires a separate, explicit apply request with selected suggestion IDs.

One folder at a time

Only the folder you enter is scanned. Hidden files and folders are skipped by default, and symbolic links are never followed.

No deletes, no overwrites

Every destination is checked again at apply time. Moves use no-overwrite primitives, and collisions are held back with a visible warning.

Journaled and undoable

Completed moves are written to a local JSONL journal. Undo only restores files whose destination still matches the recorded fingerprint.

AI output is untrusted

Only file names, extensions, and sizes are sent locally. Model JSON is validated; ids, paths, categories, and extensions are checked before use.

Local by default

The dashboard is served on localhost. There are no analytics, cloud calls, CDNs, databases, or third-party Python packages.
